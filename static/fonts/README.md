# Fonts

Self-hosted (no third-party requests) Latin subsets from Google Fonts:

- `luckiest-guy-latin.woff2`: Luckiest Guy by Astigmatic, headings and logo
- `permanent-marker-latin.woff2`: Permanent Marker by Font Diner, handwritten accents
